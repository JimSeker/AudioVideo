# CameraX API ML KitDemos

This directory is specific to the on-device ML kit (not ML cloud) APIs  https://developers.google.com/ml-kit

`BarcodeVideoXDemo`  using CameraX and camerax mlkit pieces to make simplier code.  Full video and draws the square around the barcode and diplays the numbers.

`mlkitFaceVideoXDemo` using CameraX and camerax mlkit pieces to make simplier code.  Full video and draws on the faces it sees.

`PoseVideoXDemo` This example of using the pose detection with the CameraX preview and cameraX mlkit.   There is an render issue, that appears to be a cameraX mlkit problem, not the code as far as I can tell.


Not ready yet:
`ImageLabelingDemo` This example how to use image labeling. it takes a picture and prints the object name it finds on the picture.
`FaceMeshDemo` is simple example, that uses camera intent and then draw mesh on the face.

These are example code for University of Wyoming, Cosc 4730 Mobile Programming course and cosc 4735 Advance Mobile Programing course. 
All examples are for Android.
